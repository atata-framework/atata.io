- **Atata** ([GitHub](https://github.com/atata-framework/atata) | [NuGet](https://www.nuget.org/packages/Atata/)) -
  is a core package, which provides base and main functionality for Atata testing.
- **Atata.NUnit** ([GitHub](https://github.com/atata-framework/atata-nunit) | [NuGet](https://www.nuget.org/packages/Atata.NUnit/)) -
  provides integration with NUnit testing framework.
- **Atata.Xunit.v3** ([GitHub](https://github.com/atata-framework/atata-xunit-v3) | [NuGet](https://www.nuget.org/packages/Atata.Xunit.v3/)) -
  provides integration with xUnit v3 testing framework.
- **Atata.MSTest** ([GitHub](https://github.com/atata-framework/atata-mstest) | [NuGet](https://www.nuget.org/packages/Atata.MSTest/)) -
  provides integration with MSTest testing framework.
- **Atata.Reqnroll.NUnit** ([GitHub](https://github.com/atata-framework/atata-reqnroll-nunit) | [NuGet](https://www.nuget.org/packages/Atata.Reqnroll.NUnit/)) -
  provides integration with Reqnroll+NUnit testing frameworks combination.
- **Atata.NLog** ([GitHub](https://github.com/atata-framework/atata-nlog) | [NuGet](https://www.nuget.org/packages/Atata.NLog/)) -
  adds NLog logging to Atata.
- **Atata.ExtentReports** ([GitHub](https://github.com/atata-framework/atata-extentreports) | [NuGet](https://www.nuget.org/packages/Atata.ExtentReports/)) -
  adds ExtentReports reporting to Atata.
- **Atata.Testcontainers** ([GitHub](https://github.com/atata-framework/atata-testcontainers) | [NuGet](https://www.nuget.org/packages/Atata.Testcontainers/)) -
  adds Docker container sessions to Atata using Testcontainers library.
- **Atata.AspNetCore.v8** ([GitHub](https://github.com/atata-framework/atata-aspnetcore) | [NuGet](https://www.nuget.org/packages/Atata.AspNetCore.v8/)) -
  adds ASP.NET Core 8.0 sessions to Atata using WebApplicationFactory.
- **Atata.AspNetCore.v9** ([GitHub](https://github.com/atata-framework/atata-aspnetcore) | [NuGet](https://www.nuget.org/packages/Atata.AspNetCore.v9/)) -
  adds ASP.NET Core 9.0 sessions to Atata using WebApplicationFactory.
- **Atata.AspNetCore.v10** ([GitHub](https://github.com/atata-framework/atata-aspnetcore) | [NuGet](https://www.nuget.org/packages/Atata.AspNetCore.v10/)) -
  adds ASP.NET Core 10.0 sessions to Atata using WebApplicationFactory.
- **Atata.WebDriverSetup** ([GitHub](https://github.com/atata-framework/atata-webdriversetup) | [NuGet](https://www.nuget.org/packages/Atata.WebDriverSetup/)) -
  sets up browser drivers, e.g. `chromedriver`, `geckodriver`, etc.
  Basically, it provides functionality similar to Java `WebDriverManager`.
- **Atata.HtmlValidation** ([GitHub](https://github.com/atata-framework/atata-htmlvalidation) | [NuGet](https://www.nuget.org/packages/Atata.HtmlValidation/)) -
  adds HTML page validation to Atata using [html-validate](https://www.npmjs.com/package/html-validate) NPM package.
- **Atata.Bootstrap** ([GitHub](https://github.com/atata-framework/atata-bootstrap) | [NuGet](https://www.nuget.org/packages/Atata.Bootstrap/)) -
  contains a set of Atata components for [Bootstrap Framework](https://getbootstrap.com/) web UI testing.
- **Atata.KendoUI** ([GitHub](https://github.com/atata-framework/atata-kendoui) | [NuGet](https://www.nuget.org/packages/Atata.KendoUI/)) -
  contains a set of Atata components for [Kendo UI HTML Framework](https://www.telerik.com/kendo-ui) web UI testing.
